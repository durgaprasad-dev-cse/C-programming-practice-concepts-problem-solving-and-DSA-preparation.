what is C Programming
  C is general-purpose,procedural computer programming language supporting structured programming,lexical variable scope,and recursion,with a static type system
>It was developed in the early 1970's by Dennis ritchie at Bell Labs
>Widely used for system programming,including developing operating system(like UNIX)

  C is used for:
    - System programming
    - Operating systems
    - Embedded systems
    - Compilers
    - Networking
    - Game development
